# Blockquotes and horizontal rules

## Single blockquote

> One line quote.

## Multi-line blockquote

> First line of quote.
> Second line continues.

## Nested

> Outer quote
>
> > Inner quote
>
> Back to outer.

## Rules

---

***

___

Text between rules.

---

**Checks**

- Blockquote `>` stays rendered on active line until you click the `>` marker.
- Horizontal rules render as a line (not expanding editor width).
- Rules: `---`, `***`, `___`.
